# ⏱ STM — Sirko Time Manager

**Разработчик:** Serhii Sirenko (Sirko) · Версия **0.1** · Windows 10/11

Минималистичный менеджер времени для Windows в стиле «чёрная бумага»: обратный отсчёт, планирование сна или выключения на точное время, будильники с любыми звуками и таймеры запуска/закрытия приложений по расписанию.

---

## ✨ Возможности

Вкладка | Что умеет
--- | ---
**Зворотний відлік** | Циферблат в стиле iOS (прокрутка колесом), Сон / Вимкнення, Пауза / Продолжить, сохранённые таймеры
**За розкладом** | Сон / Вимкнення в указанную точную время суток; если время прошло — на завтра
**Будильники** | Повтор по дням, название, любой звук (системные / Windows Media / свои WAV·MP3), кольцевое проигрвывание: 1 минуту, затем каждые 5 минут, пока не «Стоп»
**Таймер застосунків** | Карточки приложений: запуск и закрытие по времени, 3 ползунка (мастер/запуск/вымкнення), drag-сортировка, массовое удаление
**Налаштування** | Язык (укр / eng / рус), тёмная / светлая тема, автозапуск с Windows

Приложение живёт в трее. «Крестик» только убирает окно — таймеры продолжают работать. Полное закрытие — ПКМ по значку в трее.

## 📦 Установка

Скачай нужный релиз:

| Файл | Размер | Когда брать |
|---|---|---|
| `STM-Setup.exe` | ~221 МБ | Для любого ПК — **.NET не нужен** ✅ рекомендуемый |
| `STM-Setup-Mini.exe` | 0.5 МБ | Если у тебя есть .NET 8 Desktop Runtime |

Дважды кликни → шаги: язык → папка → переключатели (ярлыки, автозапуск) → Установить → Готово.

> ⚠️ Инсталлер не подписан цифровой подписью: SmartScreen покажет «Windows защитила» → «Выполнить всё равно».

Подробности — в `README-УСТАНОВКА.md` рядом с инсталлером.

## 🔧 Сборка из источников

```powershell
# запуск приложения для разработки
dotnet build -o bin\Test
.\bin\Test\TimerApp.exe

# сборка инсталлеров
powershell -File make-installer.ps1          # полная версия (self-contained)
powershell -File make-installer.ps1 -Mini   # лёгкая версия
```

Результат в `build\` — `STM-Setup.exe` / `STM-Setup-Mini.exe`.

## 📁 Файлы данных

| Путь | Что хранится |
|---|---|
| `%AppData%\TimerApp\alarms.json` | будильники |
| `%AppData%\TimerApp\app_timers.json` | таймеры приложений |
| `%AppData%\TimerApp\settings.json` | язык, тема |
| `%AppData%\TimerApp\Sounds\` | добавленные пользователем звуки |
